# Kimo Barcode Test

تطبيق تجريبي مستقل لقراءة الباركود على Android باستخدام Google ML Kit Bundled Barcode Scanning وCameraX.

- قراءة مباشرة بالكاميرا.
- اختيار صورة من المعرض.
- معالجة محلية على الجهاز.
- دعم PDF417 وCode 128 وCode 39 وQR وData Matrix وAztec وEAN وUPC وITF وCodabar.

يتطلب JDK 17 وAndroid SDK، والحد الأدنى Android 6.0 (API 23).

ملاحظة: نص MRZ في جواز السفر ليس باركوداً ويحتاج OCR منفصلاً.
